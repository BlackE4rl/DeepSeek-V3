# Bestätigungsregister / Acknowledgement Register — POL-AI-DACH-001

Dieses Register dokumentiert die Bestätigungen zur Richtlinie
[`POLICY_ACKNOWLEDGEMENT.de.md`](../POLICY_ACKNOWLEDGEMENT.de.md) (Leitfassung, Deutsch) bzw.
[`POLICY_ACKNOWLEDGEMENT.en.md`](../POLICY_ACKNOWLEDGEMENT.en.md) (Übersetzung).

## Verfahren

1. Richtlinie in der aktuellen Version vollständig lesen.
2. Schulung `<Schulungsmodul-ID>` absolvieren (vor der ersten produktiven Nutzung, danach jährlich).
3. Eine Zeile in der Tabelle unten ergänzen und als Pull Request einreichen — der Commit muss von der verifizierten dienstlichen Identität stammen (Signatur bzw. verifizierte Dienst-E-Mail).
4. `<AI-Governance-Stelle>` prüft und merged; damit gilt die Bestätigung als erteilt.
5. Erneuerung: spätestens nach **12 Monaten** oder bei jeder Major-Version der Richtlinie (z. B. 1.x → 2.0). Zeile ergänzen, alte Zeile nicht löschen.

**Ohne gültige Zeile in diesem Register besteht keine Nutzungsberechtigung.**
